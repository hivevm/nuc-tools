#
# A run exits 0 for pass and 1 for fail. The second field is '<key>', then ' @ <subject>' for each
# datum the line names, such as the file and line or a count. A line of the output ends in
# '[<key>]', the rule and a reason word, and holds each subject, in that order and with no ASCII
# letter, digit, hyphen, or underscore beside it; the rest of its wording is free. A line that
# starts with '#' is a comment, not a case. A field may start with '!': it then holds where no line
# that ends in '[<key>]' holds the subjects in their order.
#
# The tree is a list of steps separated by '; ', or '-' for none, applied in order to a git
# repository that passes the check, of four files:

#                             line 2, and 'echo tpl'

#                             blob of scripts/tpl.sh as written
#   src/own.rs                a file of the project: '// A short comment.' and 'fn main() {}'
#
# The steps:
#
#   rm <path>                       the file removed
#   comment <path> <marker> <n> [i] a comment line of exactly n columns appended to the file:
#                                   i spaces (0 when not given), the marker, a space, and words
#   word <path> <marker> <n>        a comment line of n columns whose text is one word
#   dash <path> <marker> <n>        a comment line of n columns whose text holds em dashes
#   code <path> <n>                 a code line of exactly n columns, with spaces
#   write <path> <text>             the file written with exactly the text, each '\n' a line break
#   blobs <path>...                 scripts/template.blobs written again, release kept, with the
#                                   blob of each path as it stands
#   release <version>               the README's Template release line names the version
